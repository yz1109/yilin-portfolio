# yilin-portfolio

This repository hosts a static portfolio website built with HTML, CSS, and images.

## Live Site

The site is published using GitHub Pages and will be available at:

https://yz1109.github.io/yilin-portfolio/

## Deployment

The repository includes a GitHub Actions workflow at `.github/workflows/deploy-pages.yml` that deploys the site automatically on every push to `main`.

## Files

- `index.html` — main portfolio page
- `cultural-buddy.html` — project detail page
- `ithaca-soap.html` — project detail page
- `styles/style.css` — stylesheet
- `images/` — image assets
